# Solstice & Company — Business Growth Agency Website

A modern, fully responsive business website for a growth marketing agency. Built with plain HTML, CSS and JavaScript. No frameworks, fast to load, and easy to customize for any client.

🔗 **Live demo:** [khudabuxmahar912-prog.github.io/solstice-website](https://khudabuxmahar912-prog.github.io/solstice-website/)

📅 **Created:** 28 September 2026
👨‍💻 **Built by:** Khuda Bux

---

## Features

- **Responsive design:** layouts adapt cleanly from mobile to desktop
- **Sticky navigation** with smooth scrolling to each section
- **Hero section** with a clear call to action
- **Case studies grid** to showcase client work
- **4-step process timeline** explaining how an engagement runs
- **Testimonial section** for social proof
- **Pricing plans** (Starter, Growth, Enterprise)
- **Contact form** with built-in field validation
- **SEO-ready:** meta description, canonical URL, Open Graph and Twitter tags, JSON-LD structured data, `sitemap.xml` and `robots.txt`
- **Google Search Console** verified

## Tech stack

| Layer | Technology |

## Run locally

1. Clone the repository
   ```bash
   git clone https://github.com/khudabuxmahar912-prog/solstice-website.git
   ```
2. Open the folder and double-click `index.html`. It opens in any browser, no build step needed.

## Customize for a client

1. Replace the business name ("Solstice & Company") in the navbar, footer and `<title>`
2. Update the text in each section (hero, philosophy, process, pricing)
3. Change the colors in the `:root` block at the top of the CSS
4. Update the URLs in the SEO tags, `sitemap.xml` and `robots.txt` to the client's domain
